# TheRealCam

Android-камера с **локальным ИИ, который учится только на снимках и оценках своего владельца**.
Модель создаётся с нуля, без чужих весов и облака. Она не перерисовывает кадр, а подбирает
параметры съёмки (выдержку, ISO, число кадров, фокус) и честно собирает серию кадров.

В одном APK два приложения:

| Иконка | Что это |
|---|---|
| **TheRealCam** | камера: режимы Авто / Ручной / AI, серии кадров, сбор датасета |
| **Real Галерея** | просмотр снимков и серий, оценка 1–10 по критериям, категории со значками |

Для ПК (Linux / Windows) есть отдельный **тренер** (`trainer/`): он обучает и дообучает модели
на выгруженном датасете. Работает на CPU, на GPU (CUDA) быстрее.

## Структура репозитория

```
android/   — Android-приложение (Kotlin, Jetpack Compose, Camera2)
trainer/   — тренер моделей для ПК (Python + PyTorch, CLI и GUI)
docs/      — концепция и форматы: датасет, файл модели .trcm, признаки
testdata/  — эталонные файлы для проверки совпадения инференса в приложении и тренере
scripts/   — вспомогательные скрипты (установка Android SDK и т.д.)
```
