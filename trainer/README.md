# Тренер моделей TheRealCam

Программа для ПК (Linux и Windows), которая обучает маленькую модель камеры **с нуля только на ваших
снимках и ваших оценках**. Никаких предобученных весов, ничего не скачивается: модель создаётся со
случайными весами и учится на датасете, который собрало приложение. Работает на CPU; если есть видеокарта
NVIDIA с CUDA — обучение заметно быстрее.

Модель не рисует и не «улучшает» пиксели. Она угадывает сцену (ваши категории: звёзды, луна, облака…)
и для каждой категории предлагает параметры съёмки: выдержку, ISO, число кадров серии, фокус на ∞ и
поправку экспозиции. Результат — файл `.trcm` (формат описан в [`docs/MODEL_FORMAT.md`](../docs/MODEL_FORMAT.md)),
который приложение исполняет само, на чистом Kotlin.

Есть командная строка и окно (GUI). Ниже `therealcam-trainer` — это то же самое, что
`python -m therealcam_trainer`.

## Установка

Нужен Python 3.10 или новее. PyTorch ставится отдельной командой — под ваше железо.

### Linux

```bash
sudo apt install python3 python3-venv python3-tk     # python3-tk нужен только для окна
cd trainer
python3 -m venv .venv
source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cpu   # только процессор
pip install -e .                                                      # сам тренер (или: pip install -r requirements.txt)
```

### Windows

Поставьте Python с [python.org](https://www.python.org/downloads/) (tkinter для окна уже входит в состав,
отметьте «Add python.exe to PATH»). Затем в PowerShell:

```powershell
cd trainer
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -e .
```

### Видеокарта NVIDIA (CUDA)

Вместо CPU-версии поставьте сборку PyTorch с CUDA — точную команду для своей ОС и версии CUDA возьмите
в селекторе на <https://pytorch.org/get-started/locally/> (вида
`pip install torch --index-url https://download.pytorch.org/whl/cu128`). Проверка:

```bash
python -c "import torch; print(torch.cuda.is_available())"     # True — GPU будет использоваться
```

Устройство выбирается автоматически (`--device auto`: CUDA, затем Apple MPS, затем CPU); можно указать
явно: `--device cpu`, `--device cuda`, `--device cuda:1`. Нашей маленькой сети хватает и процессора: 2000
снимков × 60 эпох на обычном CPU — минуты, на GPU — быстрее.

## Как достать датасет с телефона

Датасет лежит в папке приложения: `Android/data/com.therealcam/files/TheRealCam/dataset`
(внутри `dataset.json`, `categories.json` и `samples/<id>/` с `meta.json`, `thumb64.png`, `preview.jpg`,
`image.jpg`). Способы:

1. **Экспорт в ZIP** из настроек приложения (место сохранения выбирается системным диалогом). Перенесите
   ZIP на компьютер любым способом — тренер читает архив напрямую, распаковывать не нужно.
2. **По USB**: подключите телефон в режиме «Передача файлов» и скопируйте папку
   `Android/data/com.therealcam/files/TheRealCam/dataset` (или всю `TheRealCam`) на компьютер.
   Если папка `Android/data` не видна, используйте экспорт в ZIP или
   `adb pull /sdcard/Android/data/com.therealcam/files/TheRealCam/dataset`.

Тренеру можно указать саму папку `dataset`, её родителя `TheRealCam`, папку выше (он найдёт
`samples/*/meta.json` сам) или ZIP. В обучение идут только **полностью оценённые** снимки
(`labels.complete = true`) с корректной миниатюрой `thumb64.png` 64×64. Минимум — **150** снимков, чем
больше, тем лучше (2000+ — хороший уровень).

## Командная строка

```bash
therealcam-trainer inspect-dataset ~/TheRealCam                 # проверить датасет
therealcam-trainer train ~/TheRealCam -o my-model.trcm --name "Моя камера"
therealcam-trainer finetune export.zip --base my-model.trcm -o my-model-v2.trcm
therealcam-trainer inspect-model my-model.trcm                  # что внутри файла, CRC, классы
therealcam-trainer eval ~/TheRealCam --model my-model.trcm      # точность так, как увидит телефон
therealcam-trainer gui                                          # окно
```

| команда | что делает |
|---|---|
| `inspect-dataset PATH [--json]` | число снимков (найдено / полных / пропущено и почему), категории со значками и профилями, режимы съёмки, серии, гистограмма оценок, статистика меток, доступность целей, доля пропусков каждого признака, проблемы |
| `train PATH -o out.trcm` | обучение с нуля |
| `finetune PATH --base base.trcm -o out.trcm` | дообучение существующей модели (своей или чужой) |
| `inspect-model FILE [--header]` | заголовок, классы, признаки, параметры, граф; проверка CRC и графа |
| `eval PATH --model FILE [--json]` | точность категории (и среди трёх лучших), ошибка параметров; считает эталонный интерпретатор — так же, как телефон |
| `make-golden -o testdata/golden` | эталонные векторы для теста Kotlin-инференса |
| `synth-dataset OUT --n 200 --seed 1` | **синтетический** датасет только для тестов и демонстрации |

Параметры `train` и `finetune`:

| параметр | по умолчанию | смысл |
|---|---|---|
| `--name`, `--description`, `--author` | имя файла | метаданные модели |
| `--epochs` | 60 (дообучение — 30) | максимум эпох; ранняя остановка, если val loss не улучшается `--patience` (12) эпох; сохраняется лучшая эпоха |
| `--batch-size` | 64 | размер батча |
| `--lr` | 2e-3 (дообучение — 3e-4) | скорость обучения (AdamW, weight decay 1e-4, косинусное расписание) |
| `--device` | auto | auto / cpu / cuda / cuda:N / mps |
| `--seed` | 0 | воспроизводимость разбиения и обучения |
| `--delta-ev` | 0.7 | шаг поправки экспозиции по оценкам (см. ниже) |
| `--val-fraction` | 0.15 | доля валидации |
| `--allow-small` | выкл. | разрешить меньше 150 снимков — только для тестов |
| `--refit-norm` | выкл. | (дообучение) пересчитать нормализацию по новому датасету |
| `--threads` | все | число потоков CPU |

`Ctrl+C` во время обучения останавливает его после текущего батча и сохраняет лучшую на этот момент
модель; второй `Ctrl+C` — выход без сохранения.

## Окно (GUI)

```bash
therealcam-trainer-gui        # или: python -m therealcam_trainer gui
```

Выберите датасет (папку или ZIP), при желании базовую модель для дообучения, файл для сохранения, имя
модели, число эпох, размер батча, скорость обучения и устройство (auto / cpu / cuda). Кнопки:
**«Проверить датасет»** — отчёт как у `inspect-dataset`; **«Обучить»** — обучение в фоне с прогрессом,
журналом и последними метриками; **«Стоп»** — остановить и сохранить лучшую на этот момент модель. Если
выбрана базовая модель, значения по умолчанию меняются на 30 эпох и 3e-4.

## Как загрузить модель в приложение

Скопируйте файл `.trcm` на телефон (например, в «Загрузки»), в настройках TheRealCam импортируйте модель,
выберите её и включите режим **AI**. Приложение проверяет файл (сигнатура, CRC, лимиты, известные операции)
и отклонит повреждённую модель с понятным сообщением. Моделью можно поделиться — другой человек может
дообучить её на своём датасете.

## Как из датасета получаются цели обучения

Для каждого снимка модель учит **категорию** (`labels.category_id`) и **пять параметров** для этой
категории. База — то, как снимок реально был снят, поправки — по оценкам пользователя.
`DELTA` = `--delta-ev` (0.7 EV).

**База:**

* `log2_exposure_s` = log2(`capture.exposure_time_ns` / 1e9); если нет — `user_settings.exposure_time_ns`,
  затем `preview.exposure_time_ns`;
* `log2_iso` = log2(`capture.iso`); если нет — `user_settings.iso`, затем `preview.iso`;
* если нет ни выдержки, ни ISO — снимок учит только категорию (в потерю параметров не идёт);
  если нет одного из двух — не учится только он;
* `log2_frames` = log2(`series.count`) для серии, иначе log2(`user_settings.frames` или 1);
* `focus_infinity` = 1, если `capture.focus_distance_diopters` ≤ 0.1 или `user_settings.focus = "infinity"`,
  иначе 0;
* `ev_bias` = `capture.ev_compensation`, если нет — `user_settings.ev`, иначе 0.

**Поправки по меткам** (применяются по порядку):

1. `exposure = −1` (темно): при смазе (`motion_blur = 1`) ISO += DELTA, иначе выдержка += DELTA/2 и
   ISO += DELTA/2; EV += DELTA.
2. `exposure = +1` (пересвет): выдержка −= DELTA/2, ISO −= DELTA/2, EV −= DELTA; если ISO стал ниже
   минимального ISO сенсора (`device.iso_range[0]`, когда он известен) — ISO ставится на минимум, а
   недостающее уходит в уменьшение выдержки.
3. `motion_blur = 1`: выдержка −= 1, ISO += 1 (короче выдержка, выше ISO).
4. `noise = −1` (шумно): при смазе число кадров += 1 (log2, т.е. вдвое больше кадров), иначе ISO −= 0.5 и
   выдержка += 0.5.

**Веса:**

* вес параметров снимка = 0.05 + ((оценка − 1) / 9)²: снимки на 10 баллов учат параметры в ~20 раз
  сильнее, чем на 1; кадры серий (`series.role = "frame"`) дополнительно ×0.5 — для параметров важнее
  одиночные снимки и итоги серий;
* вес класса = 1/√(число снимков класса), нормированный к среднему 1 — редкие категории не теряются;
* все снимки одной серии делят вес группы: каждый ×1/√(размер серии), чтобы серия из 30 кадров не
  перевешивала датасет.

**Разбиение и признаки:**

* train/val ≈ 85/15 по каждому классу; серия (`series.series_id`) целиком уходит либо в train, либо в
  val; одиночный снимок — сам себе группа; в train всегда остаётся хотя бы один снимок каждого класса;
* признаки сцены берутся из `meta.json → features` как есть (тренер их не пересчитывает); используются
  те из 33 признаков схемы 1, что заполнены хотя бы в 10% обучающих снимков; нормализация — среднее и СКО
  по заполненным значениям (СКО < 1e-3 → 1); пропуск → 0 после нормализации, ограничение [−6, 6] — ровно
  как в приложении;
* параметры нормализуются средним и СКО целей (СКО не меньше 0.25); `focus_infinity` — логит
  (mean 0, std 1), учится бинарной кросс-энтропией.

**Потери:** кросс-энтропия по категории (label smoothing 0.05, веса классов) + smooth-L1 по четырём
числовым параметрам строки **верного** класса + BCE для `focus_infinity`; недоступные цели маскируются.
Аугментации: отражение, сдвиг до ±4 px, лёгкие яркость/контраст, шум; шум признаков σ=0.05 и случайное
«выпадение» признака (p=0.05).

## Дообучение

```bash
therealcam-trainer finetune ~/TheRealCam --base friend-model.trcm -o my-model.trcm
```

* Классы сопоставляются по `id` категории. Классы базовой модели остаются первыми (имя и значок
  обновляются, если такая категория есть в вашем датасете), новые категории добавляются в конец со
  свежими случайными весами — выходы старых классов до обучения не меняются.
* Классы базы без снимков в вашем датасете сохраняются как есть.
* Список признаков и нормализация берутся из базовой модели. `--refit-norm` пересчитывает их по новому
  датасету, при этом веса первого слоя и головы параметров пересчитываются так, что модель до обучения
  выдаёт те же значения.
* BatchNorm в файле уже «свёрнут» в свёртки, поэтому при дообучении его статистики заморожены.
* В заголовок записывается `training.baseModel` (имя базовой модели) и её SHA-256.

Дообучать можно модели, созданные этим тренером (архитектура TrcNet); для другого графа будет понятная ошибка.

## Модель

`TrcNet`: миниатюра 64×64 → [свёртка 3×3 → BatchNorm → ReLU → MaxPool 2] ×3 (16, 32, 48 каналов) →
свёртка 3×3 (64) → BatchNorm → ReLU → глобальное среднее; склейка с нормализованными признаками →
Linear (96) → ReLU → Dropout 0.2 → две головы: логиты категорий `[K]` и параметры `[K·5]`. Около 58 тыс.
весов, файл ~235 КБ. При экспорте BatchNorm сворачивается в веса свёрток, Dropout выбрасывается — в файле
только операции спецификации (`conv2d`, `relu`, `maxpool2d`, `global_avgpool`, `concat`, `dense`).

`therealcam_trainer/reference.py` — эталонный интерпретатор `.trcm` на NumPy (все операции спецификации).
Им проверяется каждый экспорт, им работает `eval`, им же посчитаны эталонные векторы
`testdata/golden/` (модель + `golden.json`), с которыми сверяется Kotlin-движок приложения.

## Сборка exe (PyInstaller)

Собирать нужно на той ОС, для которой нужна сборка. В окружении, где тренер уже работает:

```bash
pip install pyinstaller
cd trainer
pyinstaller packaging/therealcam_trainer.spec
```

Результат — папка `dist/TheRealCamTrainer/` с двумя программами: `therealcam-trainer-gui` (окно,
на Windows `therealcam-trainer-gui.exe` без консоли) и `therealcam-trainer` (командная строка). Папку
можно переносить целиком. В сборку попадает установленный PyTorch: с CPU-сборкой torch папка занимает
меньше 1 ГБ, с CUDA-сборкой — несколько ГБ.

Если окно собранной программы пишет, что не найден tkinter (бывает с Python, установленным через
pyenv/uv, где библиотеки Tcl/Tk лежат вне стандартных путей), соберите заново, добавив путь к ним:
`LD_LIBRARY_PATH=<папка python>/lib pyinstaller packaging/therealcam_trainer.spec`. С системным Python
(`python3-tk`) на Linux и с Python с python.org на Windows это не нужно.

## Синтетический датасет, эталоны и тесты

`synth-dataset` создаёт **синтетический** датасет в точном формате приложения (звёзды, луна, облака,
«другое» — картинки и признаки сгенерированы, всё помечено как SYNTHETIC). Он нужен только для тестов и
демонстрации; настоящую модель обучайте на своих снимках.

```bash
pip install pytest
cd trainer
python -m pytest                                  # все тесты, меньше минуты на CPU
python -m therealcam_trainer make-golden -o ../testdata/golden
```

`make-golden` детерминированно (фиксированный seed) обучает архитектуру по умолчанию 2 эпохи на
синтетических данных, экспортирует `model.trcm` и пишет `golden.json` с 6 случаями (случайная картинка,
звёзды, пересвеченное небо, полностью чёрная картинка, луна с выходящими за ±6 признаками, серая текстура;
часть признаков `null`). Ожидаемые выходы считает эталонный интерпретатор и перепроверяет PyTorch.
